# Dial Booster - Jogo de Apostas Interativo

Um jogo de apostas interativo baseado em um sistema de dial giratório e multiplicadores de booster.

## Características

- Design responsivo mobile-first
- Interface com dial giratório interativo
- Sistema de multiplicadores de booster
- Três fases progressivas com diferentes níveis de dificuldade
- Feedback visual e sonoro
- Armazenamento local de saldo do jogador

## Tecnologias

- HTML5, CSS3, JavaScript
- LocalStorage para persistência de dados
- Animações CSS e JavaScript

## Como Jogar

1. Inicie com R$ 10,00 de saldo
2. Receba um multiplicador aleatório de booster (2X a 5X)
3. Escolha um valor para apostar
4. Complete as três fases girando o dial para encontrar o número correto
5. Ganhe ou perca com base no seu desempenho

## Desenvolvimento

Para executar o jogo localmente, basta abrir o arquivo `index.html` em um navegador moderno.
