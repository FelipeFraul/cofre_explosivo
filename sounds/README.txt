Sound Files for Dial Booster Game

This directory should contain the following sound files:
- countdown.mp3: Sound for the countdown timer
- success.mp3: Sound for successful selections
- failure.mp3: Sound for unsuccessful selections
- dial.mp3: Sound for dial rotation
- correct.mp3: Sound for correct number selection

Please add appropriate sound files with these names to enable audio feedback in the game.

You can find free sound effects at:
- https://freesound.org/
- https://mixkit.co/free-sound-effects/
- https://www.zapsplat.com/

For the best experience, use short MP3 files (1-2 seconds) with clear, distinct sounds.
